## 🎯 Sound Design Tips

### Make a Screaming Laser
1. OSC1 Level: 1.0
2. OSC1 WT Pos: 0.8
3. OSC1 Warp: 0.9
4. Filter Cutoff: 4000Hz
5. Filter Resonance: 0.8
6. Env1 Attack: 0.01s
7. LFO1 Rate: 3Hz
8. LFO1 Depth: 0.7

Result: Piercing hi-tech screech.

---

### Make an Acid Bass
1. OSC1 Level: 1.0
2. Sub Level: 1.0
3. Filter Cutoff: 800Hz
4. Filter Resonance: 0.7
5. Env2 Decay: 1.0s (long filter sweep)
6. Env2 Release: 0.3s

Result: Classic squelchy acid bass.

---

### Make a Psychedelic Texture
1. OSC1/OSC2/OSC3 all active with different WT Pos
2. FM cross-modulation enabled
3. Reverb Mix: 0.5
4. LFO modulating filter cutoff slowly

Result: Evolving alien soundscape.
